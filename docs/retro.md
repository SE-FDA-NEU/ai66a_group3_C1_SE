# Sprint 1 Retrospective

Date: 2026-09-14

## Context

Sprint 1 focused on making the AI Movie Recommendation System ready for real
implementation: process rules, issue templates, Sprint 1 board setup, the first
traceability skeleton, and a product backlog for recommendations, movie details,
ratings, filters, and similar movies.

The sprint produced useful structure, but the team committed more work than it
could close with evidence. At wrap-up, committed issues #11-#24 were still open
on GitHub and no committed Sprint 1 story had a linked merged PR.

## What Went Well

- The team created a visible GitHub workflow with issue templates, labels, CI,
  Scrum hygiene checks, a Definition of Done, and process documentation.
- Product stories were written from the user's point of view and included
  acceptance criteria and estimates for the main recommendation workflows.
- Ownership was clear on the Sprint 1 issues, so the next Scrum Master can see
  who was responsible for each item.

## What Did Not Go Well

- Too many issues were committed at once, especially before earlier process
  chores were actually closed.
- Work moved on the board without enough GitHub comments, PR links, or merged
  evidence to prove what changed.
- Review and retro attendance were not recorded during the event, which makes
  the final process evidence weaker than the team's actual discussion.

## What We Learned

The team can set up process infrastructure quickly, but Sprint 2 needs a smaller
work-in-progress limit and stronger evidence habits. A story should not be
treated as nearly done unless its PR, review, test evidence, and traceability
updates are visible in GitHub.

## Keep / Stop / Start

| Keep doing | Stop doing | Start doing |
|------------|------------|-------------|
| Keep using GitHub issues, labels, PRs, and traceability docs as the shared source of truth. | Stop leaving issue progress, blockers, and review status outside GitHub where the next Scrum Master cannot verify them. | Start one mid-sprint board check that records a next step or blocker on every issue that has not moved. |
